# GameField
Лабораторная работа №1: Игровое поле и юниты (ММО РПГ)

Описание
Проект реализует систему игрового поля и иерархию юнитов с использованием принципов ООП, умных указателей и паттернов проектирования на C++.

Выбран паттерн «Фабричный метод», так как задача требует создавать конкретные объекты юнитов по их типу, а не целые семейства связанных продуктов. Это позволяет инкапсулировать логику создания и защищает код от ошибок, запрещая некорректные комбинации (например, создание лучника через фабрику пехоты).
